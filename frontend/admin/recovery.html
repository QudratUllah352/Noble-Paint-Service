Recover an interrupted operation

  1. Copy the exact command from the report.
  2. Stop all backend instances and workers, including any running on another machine. For a scheduling lock, review the saved appointments and reconcile any unfinished write before releasing it.
  3. For email, check the customer inbox or provider logs. Choose received to record verified receipt, or retry to allow a manual resend. A retry may duplicate delivery.
  4. Run the command from the backend folder and enter your current admin credentials when prompted. Password input is hidden.
  5. Restart the backend and review the appointment and its history. Recovery never sends an email automatically.

These commands require terminal access. Changes cannot be made from this page while the server is running. See backend/SETUP.md for details.
